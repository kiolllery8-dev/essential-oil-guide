# 精油站事件定義

此草稿量測手動生命靈數計算漏斗。正式部署後才會開始累積；本機測試流量封鎖外部請求，不傳送到 GA4。

| 事件 | 觸發條件 | 解讀範圍 |
| --- | --- | --- |
| `numerology_calculate` | 使用者點擊計算，現有同步生成器成功更新有效結果 | 每次手動成功計算一次；重算是新事件 |
| `numerology_result_view` | 同次手動成功計算的第一張主命數卡片頂端进入畫面 | 每次計算至多一次；不代表讀完命盤 |
| `related_oil_click` | 同站精油指南或數字 ID 精油頁連結的使用者點擊 | 全站任何區塊皆算入，不能直接當成文章末尾推薦成效 |
| `related_article_click` | 同站 `/article-.../` 連結的使用者點擊 | 全站任何區塊皆算入，不代表後續閱讀 |

回訪者自動恢復的命盤不列入手動漏斗。下一次點擊計算會結束前次未完成的結果瀏覽觀測，包括無效輸入；因此這組事件不表示所有命盤曝光。

自訂參數只有 `page_path`、`tool`、`target_path`，且路徑經白名單檢查，不含 query 或 fragment。不讀取或傳送生日、姓名、數字結果、聊天內容。GA4 自動頁面參數仍遵循網站既有設定。

以 property `534422514` 且 hostname `intelliverse.tw` 分析。此草稿尚未包含調配完成事件，不能聲稱已驗證完整調配漏斗；也不能將事件數當成人數或流量增長。
